# Panel-v3 探索协议（2026-11-21，运行前固定）

## 动机和假设

panel-v2 的目标写作“打开所有红灯”，却以红灯且读数高的区域必须关闭评分；模型实际将二者视为冲突。本版本仅澄清红灯区域须受适用操作限制约束，不在目标中给出封锁规则、读数或阈值。原版结果不变，两个版本不构成严格配对。

探索性假设：当模型获得仅从训练任务评分标签和预设整数阈值假设类中归纳的规则，且任务文字不再与评分规则直接矛盾时，保留测试集的 lockdown 准确率可能高于无记忆 V1。此试验不测试模型自主归纳，也不证明因果演化。

## 固定设计

- 数据 `panel-v3`；训练初始种子 3000–3006，测试种子 4000–4003。测试图片及标签不得参与边界选择、提炼或回放验证。
- 两臂顺序为 V2-threshold、V1。阈值臂基于训练反馈从剩余整数阈值的中点选择下一训练面板的读数；V1 复用完全相同的训练和测试图片。两臂使用相同模型、工具、目标、步数与初始空记忆。
- 候选必须在所有已完成训练样本上程序化回放，存在多个一致阈值时保持 pending。测试阶段冻结记忆。如果训练结束没有激活规则，明确标记干预未形成，不能把两臂结果当作验证记忆收益。
- 主要报告总体成功、lockdown 和 target 检查、配对差异、置信区间、调用与 token 消耗。4 对任务仅为探索性；无论结果如何均如实报告，不使用该测试集迭代任务文字或选择阈值。
- 共用第三阶段 450 请求、100 万 token 账本；未知用量或响应异常立即停止。图片 token 的预留只是估算，不能保证服务端绝不超出预留。

## 动作输出上限调整（第一次尝试中断后，重试前记录）

首次真实尝试在第四个训练面板的动作调用返回空内容，`finish_reason=length` 且 1200 个输出 token 均为推理，未接触测试任务。为重试该次未完成的对照，两臂动作调用输出上限统一由 1200 提到 2400；保留原始中断记录，任务、样本与其余配置不变。此次是动作调用失败的第一次重试，受每个失败操作最多两次重试约束。

第一次重试在首个训练面板再次空响应，推理 token 达到 2400。第二次也是最后一次重试前，两臂动作上限统一设为 4800；如果仍失败则停止，不再直接重试。两次中断均未执行保留测试。
