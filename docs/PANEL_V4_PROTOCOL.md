# panel-v4 预注册协议

预注册时间：2026-11-21，在运行任何调用之前固定。

## 为什么需要新协议

- `panel-v3` 的 4 个保留测试已被观察（V2-threshold 4/4）。在那 4 题上再调方法等于在测试集上选型。
- `panel-v3` 的 V1 臂在训练期中断，从未产出配对对照，因此**至今没有一次完整的视觉配对实验**。
- 前三次模型自由提炼（900/1800/3200 输出 token）全部空响应，已达重试上限，不重复。

## 假设（有界、可证伪）

**H-V4**：把"红灯且读数 ≥ T 时不操作"这条记忆以**程序化诱导的阈值 + 一行注入文本**的形式交给模型，
它与"无记忆"在同一批测试面板上的成功率差 ≥ 1 个任务（4 个中的 1 个）。

不支持的条件：差值 < 1 个任务，或任一臂未能完成全部 4 个测试面板（后者记为"实验未完成"，
不得解释为负结果）。

## 与之前失败操作的区别（必须明说）

| | 之前的 V2-new | 本协议 V2T |
|---|---|---|
| 规则来源 | 模型自由归纳（开放生成） | 训练面板的程序化评分标签 + 声明的整数阈值假设类 |
| 模型输出 | 一整条规则文本 | 无（模型不参与归纳） |
| 失败模式 | reasoning 耗尽 → 空响应 | 只剩"执行"这一步，即已在多处验证过的动作调用 |

这不是"再试一次"，是换掉了失败的那一步。

## 固定参数

| 项 | 值 |
|---|---|
| 模型 | `deepseek-flash`（不切换） |
| 训练种子 | 5000, 5001, 5002, 5003（此前从未使用） |
| 测试种子 | 6000, 6001, 6002, 6003（此前从未使用） |
| 假设类 | 红灯区域内 `readout >= T`，T 为 0..99 的整数 |
| 诱导方式 | ~~训练面板的评分标签枚举 T~~ → **协议修订二（仍在任何测试面板运行之前）**：见下方"标签是定义性的" |
| 边界探测 | ~~二分探测~~ → 取消，理由同上 |
| 诱导失败 | 若 T 不唯一或不存在 → V2T 臂记为"未产出候选"，实验记为未完成 |
| 动作预算 | 每面板 `max_steps = zones*3 + 8`；单次调用 `max_tokens = 1200` |
| 训练/测试隔离 | 测试面板不参与诱导；两臂使用**同一批**测试面板（哈希记录在结果文件里） |

| 主要指标 | 4 个测试面板上的程序化成功率（`targets_switched_on` 且 `lockdown_respected`） |
| 次要指标 | 各检查项通过数、token、工具调用数 |

## 主对照

同一批 4 个测试面板、同一模型、同一工具、同一动作预算：

- **V1**：有图、无记忆。
- **V2T**：有图 + 训练诱导出的阈值规则（一行注入文本：红灯且读数 ≥ T 时不操作）。

两臂顺序执行，各自独立的运行目录；测试面板图像字节 SHA-256 必须相同（结果文件记录）。

## 统计

4 个配对样本。**任何差异都不可能达到 p<0.05**（3 个 discordant pair 时 p=0.25）。
因此本协议**只报告逐任务配对结果与方向**，不声称有效性。要得到显著结论需要约 20 个测试面板。

## 不作数的情形（事先写死）

- 任一臂未跑完 4 个测试面板 → 实验未完成。
- 诱导出的 T 不唯一 → 实验未完成。
- 测试面板哈希不一致 → 配对无效。
- 出现原因不明的空响应并在同一操作上重试两次仍失败 → 实验未完成，记录阻塞。

## 协议修订二：这一臂是 oracle 上界，不是"学习"

在跑完 4 个训练面板中的 2 个之后（`artifacts/stage3/panel_v4_20261121T065902650321Z/`，
消耗 44 次调用、约 74k token）发现一个必须先讲清楚的事实：

**训练面板的标签是定义性的。** `expected_action` 由任务生成时的隐藏规则直接算出
（`is_lockdown` → `leave_off`），与模型在训练面板上做了什么无关。因此：

- 跑训练面板不会让阈值变得更可确定，它只是把已知的东西再花 2 万 token 观察一遍；
- 把这种流程写成"从训练反馈中学习"会误导——它更像"直接读答案"。

### 修订后的设计

- 取消训练面板与二分探测（共省下 ~130 次调用）。
- 阈值按定义从任务生成器取（`LOCKDOWN_READOUT = 50`）。
- 实验定性改为：**"如果记忆完全正确，它能带来多少提升"的上界测量**，
  即 oracle-conditioned 记忆臂，而不是学习方法。

### 这样还能回答什么

仍能回答一个真问题：**在真实模型 + 真实视觉下，一条完全正确的排除规则，
是否足以把 lockdown 违规降到零，以及它会不会带来过度排除。**

这不能回答"系统能否自己学到这条规则"。那需要模型自主归纳，而开放归纳已在
900/1800/3200 输出 token 三次失败，属于已知阻塞。

### 相应地，本实验的结论只能表述为

> 在 4 个未见过的测试面板上，一条**已知正确**的排除规则使成功率从 X/4 变为 Y/4。

不能表述为"视觉记忆学会了规则"或"系统具备经验演化能力"。
